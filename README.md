# Rule-Based Chatbot 🤖

This is a simple rule-based chatbot created using Python.
The chatbot responds to user inputs using predefined rules.

## Features
- Greets the user
- Responds to common questions
- Ends conversation on 'bye'

## Technologies Used
- Python

## How to Run
1. Install Python
2. Run chatbot.py
3. Type messages in the terminal
